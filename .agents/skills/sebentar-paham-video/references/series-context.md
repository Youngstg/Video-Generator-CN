# Established preferences and precedence

Use this as a compact editorial memory. The latest explicit user request overrides these defaults.

| Decision | Established direction |
|---|---|
| Content | One useful, surprising fact with background and a readable mechanism. The user rejected seven dense facts and rushed delivery. |
| Identity | “SEBENTAR, PAHAM.” Warm pastel editorial motion; preserve a coherent series while drawing a new subject each time. |
| Visual revision | The user rejected generic boxes of numbers/data standing in for Earth, satellites, mouse and other subjects. The actual object must be recognizable and prominent. |
| Language | Relaxed Indonesian; preserve technical English, especially **source code**. Avoid awkward literal translations. |
| Pace | Clear and curious, enough space to understand. Never solve an overlong script solely by speeding up speech. |
| Voice | Episodes 1–13 are the expressive reference. The recovered guide identifies Brodie / eleven_v3. That is a tonal reference, not permission to buy a voice or imitate a person. Later Edge narration was rejected as flat. |
| Ending | Change cadence: warmer, slightly slower, resolved. It must not sound identical to the middle. |
| Visual quality (Oct 2026) | The user found videos not eye-catching enough and saw text spilling outside boxes. Visuals need a strong hook, one focal subject, varied compositions and motion; text must be built inside boxes, enforced by `lint`. |
| Timeline bar | Remove it. No progress bar in future videos. |
| Topics | When asked for topics first, wait for selection. Once selected, produce without redundant confirmation. Avoid repeating old facts; check the ledger and previous angles. |
| Provider quota (Oct 2026) | The free Gemini TTS tier ran out because each episode used seven requests. Use one request per episode (single take, then split), never retry quota errors, fall back per whole episode. |
| Costs | No added payment. Gemini Pro does not by itself establish usable TTS/API access. Do not repeat the unsuccessful browser login workflow. |
| Default delivery | Vertical MP4 + separate clean narration WAV only. Video has the full mix. Keep scripts, SRT, research, covers and QA internal; no horizontal export or ZIP by default. |
| Portability | Keep the same skill usable in Codex and Antigravity; discover tools available in each host. |

The original dark-terminal palette, seven-fact format, progress bar and publishing bundle are superseded. Never treat them as current simply because they appeared in the first prompt.

Keep source project history honest. The seed records recovered mappings and explicitly names gaps. Empty/missing folders do not prove a video never existed; inspect real MP4s and source projects before concluding.
